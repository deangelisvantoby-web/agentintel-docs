Getting started

Once you've been issued an API key, send a GET request to the analysis endpoint with a supported website URL.

GET/analyze?url=...
curl -H "X-API-Key: YOUR_API_KEY" \
"https://agentintel-api.deangelisvantoby.workers.dev/analyze?url=https%3A%2F%2Fwww.briskcoffee.com%2F"
Replace YOUR_API_KEY with your issued key. Never put an API key in a URL or expose it in public frontend code.

Authentication

The analysis endpoint requires an API key sent in the X-API-Key request header.

X-API-Key: YOUR_API_KEY

Requests with missing, invalid, or revoked keys are rejected. Keep your key in a secure server-side environment variable.

Response structure

Successful responses contain structured company information and analysis metadata. The following is an illustrative excerpt, not a complete live response schema.

{
  "analysis": {
    "pages_fetched": 2,
    "incomplete": false,
    "warnings": [],
    "robots_txt_checked": true
  },
  "quality": {
    "score": 100,
    "maximum_score": 100,
    "note": "Coverage score only; not factual accuracy or independent verification."
  }
}

Additional response fields include extracted company information, public contacts, social links, and supporting verification details. Field availability depends on the website.

Data quality and limitations

AgentIntel analyzes public information available from supported websites. Extracted contact information is not independently verified for ownership, deliverability, or accuracy.

Quality scores measure coverage of selected fields, not the factual correctness of those fields. Review important information before using it in consequential workflows.

Respect applicable privacy, website-access, and outreach requirements when using extracted information.
